# Car-pick-menu
Пример кода меню выбора автомобиля для мультиплеерной гонки в Unity.
Отображает доступные автомобили и их характеристики, сохраняет выбор игрока и запускает поиск матча либо подготовку к групповой гонке. Использует MVP, Strategy, R3, UniTask и VContainer.
Это демонстрационный пример для оценки кода. Файлы взяты из проекта без зависимостей, сцен и префабов. Отдельно код не компилируется и не запускается.
